Posterior validation

BayesianDiffEq.sbc — Function
sbc(model_generator::Function, n_rep::Int; sampler = NUTS(), n_samples = 500)

Simulation-based calibration (Talts et al., 2018). For n_rep rounds: draw parameters from the prior, simulate data, sample the posterior, and record the rank of the true parameter within the posterior draws. For a correctly specified model and sampler the ranks are uniform; strong deviations (U-shapes or spikes) indicate bias or over/under-confidence.

model_generator is a function of no arguments returning a (model, theta_true, data) triple.

Returns a matrix of ranks, size (n_params, n_rep).

BayesianDiffEq.coverage_of_credible_intervals — Function
coverage_of_credible_intervals(coverage_runs; alpha = 0.9)

Given a vector of NamedTuples or pairs (truth, draws) where draws is an n_params x n_samples matrix of posterior samples, compute the empirical coverage of the alpha central credible intervals.

BayesianDiffEq.posterior_predictive — Function
posterior_predictive(prob, t, theta_draws; solver = Tsit5(), kwargs...)

Simulate the dynamical system at each posterior draw. Returns a vector of solutions, one per column of theta_draws (size n_params x n_samples), which can be plotted against the data as a posterior predictive check.

source
BayesianDiffEq.map_initialization — Function
map_initialization(model; maxiters = 2000, fallback = NamedTuple())

Compute a maximum-a-posteriori estimate of model using L-BFGS and return it as a NamedTuple suitable for the init_params keyword of sample. Returns fallback (default: empty NamedTuple, i.e. no explicit initialization) if the optimization does not converge.

Example

init = map_initialization(model)
chain = sample(model, NUTS(), 500; init_params = init)
